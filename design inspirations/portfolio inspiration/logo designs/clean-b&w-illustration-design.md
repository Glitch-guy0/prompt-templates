# Design Language Report — "Illustrated Mark" Team/Bio Page Style

A reference for building pages in this visual system, defined purely as principles and philosophy so new illustrations, names, and copy can be generated fresh in this style rather than copied from any single instance.

## 1. Core Character
A single-color brand page where a **bespoke line-art character illustration functions as the logo/brand mark** for each entry — the illustration is the hero element, not a decorative accessory to it. Text is secondary and purely informational; the drawing carries the brand's personality and is the thing the reader remembers.

**Keywords:** illustration-as-logo, single-color-field, hand-drawn-line-art, quiet-typography, confident-flat-color.

## 2. Color Palette
- **One saturated brand color as the entire page background** (a confident, single hue — e.g. a strong blue, green, or terracotta) — no white background anywhere, no secondary hue.
- **Illustrations and text render in a single dark ink color** on top of that field (near-black outlines, near-black type) — effectively a two-tone system: field color + ink color, nothing else.
- Illustration panels sit in a **slightly lighter/tinted rectangle** of the same hue family, just enough value shift from the page background to read as a distinct "card" without needing a border-color change — separation through subtle tonal shift, not contrast.
- No gradients, no shadows, no secondary accent — color restraint is the entire visual strategy.

## 3. Layout System
- **Single-column, vertically stacked repeating unit:** illustration card → name → role tag → short bio paragraph → (repeat). No grid, no sidebar — this is a scrolling, story-like sequence rather than a dashboard.
- Each illustration lives inside a **thin-bordered rectangular frame**, full-bleed within the column, generous padding around the figure so it has visual breathing room — the character always stands centered with empty space around it, never crops.
- Text block beneath each illustration is **left-aligned, tight and modest in scale** relative to the illustration above it — the illustration is allowed to dominate the vertical space; text is a caption, not a headline competing for attention.
- Consistent spacing rhythm between illustration → name → tag → paragraph → next illustration; the repetition of this exact sequence is what makes the page feel systemized rather than ad hoc.

## 4. Typography
- Name set in a **clean, medium-weight sans-serif**, noticeably larger than the body copy but still modest in scale (not a shouting headline) — a person's name is signal, not spectacle.
- Role/title is a **small label prefixed with a bullet/dot marker**, set smaller and lighter than the name — functions like a tag, not a subheading.
- Bio paragraph in a **regular-weight sans-serif**, comfortable line-height, conversational sentence length — reads like a short editorial blurb, not marketing copy.
- Only one type family is implied throughout (no mono/serif mixing) — typographic simplicity so the illustration remains the only "loud" element on the page.

## 5. Components & Patterns
- **Illustration frame:** thin single-color outline rectangle containing a full-figure, hand-drawn-style line illustration of a person, doodle-like props included (laptop, coffee cup, portfolio) that hint at the person's role without needing icons or labels — the props do the "role signaling" job visually.
- **Ground shadow:** a simple flat ellipse beneath each figure's feet — the one recurring "grounding" device that keeps every illustration visually anchored the same way.
- **Name + tag pairing:** name directly above a bulleted one-line role descriptor — this pairing is the standard caption block under every illustration.
- **Bio paragraph:** consistently 4–6 sentences, ends on a light, personable, slightly humorous personal-interest detail — structurally: credentials/experience → philosophy or approach → a human/quirky closing note.
- **Repeat unit as the whole page:** the entire "team page" is just this illustration+caption block duplicated per person, stacked vertically with consistent spacing — no additional layout complexity is introduced.

## 6. Illustration Style (the core brand asset)
- **Uniform line weight**, monochrome (ink-on-field, no fill shading) — illustrations read as line drawings, not flat-color icon illustrations.
- Figures are **stylized but proportionally grounded** (slightly elongated, simplified facial detail, expressive stance) — approachable rather than photorealistic or corporate-clip-art.
- Each figure holds/wears **1–2 props specific to their role** (a device, a bag, a drink, a clipboard) — minimal narrative detail rather than generic stock-avatar poses.
- Because this illustration style is consistent across every entry, it functions as a **recognizable brand system in itself** — much like a wordmark or logo mark would, it should be reusable, consistent in weight/proportion, and instantly attributable to the brand even without accompanying text.

## 7. Principles to Carry Forward
1. **Treat the illustration as the logo.** Design the drawing first as a standalone brand mark that must work with zero text beside it; everything else on the page supports it.
2. **Two colors, one job each.** One saturated field color for atmosphere, one ink color for everything drawn or written — resist adding a third color anywhere.
3. **Separate by tone, not by border weight.** Use a slightly lighter/darker tint of the same hue to distinguish a "card" from its background rather than introducing a new color or heavy stroke.
4. **Let the drawing breathe.** Keep generous empty space around each figure inside its frame — cropping or crowding the illustration undercuts its "hero" status.
5. **Keep captions modest.** Name, role tag, and bio should never visually compete with the illustration in scale or color — they are support copy.
6. **One repeatable unit, not a layout system.** Resist adding grids, columns, or varied card types — the strength of this style comes from disciplined repetition of a single block.
7. **Consistency across instances is the brand.** The illustration style (line weight, proportions, prop logic, ground-shadow) must stay identical from one entry to the next — consistency, not variety, is what makes the illustrations read as an owned brand asset.

---
*Use this as a style brief to generate original illustrations, characters, and copy in this style — the illustration-as-logo philosophy, two-tone color discipline, and repeating caption structure are what define the style, not any single character, name, bio, or exact color value.*
